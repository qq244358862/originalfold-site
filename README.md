# 原始折叠 · Original Fold

成都原始折叠科技有限公司的公开网站。拖动首页的黑色三维折纸，或打开作品扇，翻看「想过」「段落计时器」。联系：hello@tianmengdesign.com。

- `index.html`：官网、公司和联系信息，含无脚本作品入口。
- `style.css`：桌面与移动排版。
- `fold.js`：纸张几何、光照、鼠标与触摸拖动。方向键旋转，Shift + 方向键平移，Home 复位。
- `fan.js`：折扇开合、项目扇叶和来回折叠动画。支持键盘、浏览器前进后退、作品深链接和减少动态效果。
- `studio.js`：复制联系邮箱。
- `mark.svg`：品牌标志。

直接用浏览器打开 `index.html`，或在此目录执行 `python -m http.server 8000` 预览。无需安装依赖，所有资源均随仓库发布。GitHub Pages 使用 `main` 分支根目录。
