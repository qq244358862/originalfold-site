# 原始折叠 · Original Fold

成都原始折叠科技有限公司的公开网站。首页展示可拖动的黑色折纸、联系区和公司页脚，导航提供「作品」和「联系我们」。联系：hello@tianmengdesign.com。

「作品」或「浏览作品」以首屏底部的水平分隔线为折痕，把印有「想过」和「段落计时器」的作品纸分段向下翻开。上方首屏保留，联系区随纸面下移。「收起作品」、Esc 和浏览器后退沿同一轨迹收回；直接链接 `#works` 会打开作品。

- `index.html`：首页、两张作品卡和联系信息。
- `style.css`：响应式排版、纸张样式与作品插画。
- `fold.js`：黑色三维折纸；支持鼠标、触屏、方向键旋转，Shift + 方向键平移，Home 复位。
- `portfolio.js`：水平折痕、纸面的展开高度及键盘、历史记录和减少动态效果支持。
- `contact.js`：复制联系邮箱。`mark.svg`：品牌标志。

无需安装依赖或构建。解压后打开 `index.html` 即可预览，或在目录中运行 `python -m http.server 8000`。GitHub Pages 使用 `main` 分支根目录。
