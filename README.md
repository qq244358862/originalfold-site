# 原始折叠 · Original Fold

成都原始折叠科技有限公司的公开网站。官网首页展示可折叠、可旋转的三维纸带，介绍「想过」「段落计时器」，并提供工作室的联系邮箱。

## 文件

- `index.html`：页面结构、公司信息与产品链接。
- `style.css`：桌面与移动端样式。
- `fold.js`：连续纸带的三维几何、光照与交互。支持鼠标、触摸、方向键和减少动态效果。
- `studio.js`：复制联系邮箱。
- `mark.svg`：品牌图标。

## 运行与发布

全部资源随仓库提供，不需要安装包或构建。直接打开 `index.html`，或在此目录运行 `python -m http.server 8000`。GitHub Pages 使用 `main` 分支的根目录。
